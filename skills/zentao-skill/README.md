# ZenTao Bug Fix Skill

这是一个面向工作流的 Skill，用于串联 **禅道 (ZenTao)** 和 **GitLab**，实现从 Bug 诊断到修复提交的自动化。

## 目录结构
```
zentao-skill/
└── SKILL.md    # 核心工作流定义
```

## 功能特性
1. **自动诊断**: 根据 Bug ID 自动从禅道抓取重现步骤和附件。
2. **上下文补全**: 自动识别缺失信息（如分支、仓库、文件路径）并引导用户提供。
3. **信息回填**: 将用户提供的修复背景自动记录到禅道备注，确保信息同步。
4. **自动化修复**: 自动创建修复分支、提交代码并生成 GitLab Merge Request。

## 依赖
- **zentao-mcp-server**: 用于与禅道实例交互。
- **gitlab-skill**: 用于操作 GitLab 仓库。

## 使用方法
你只需对 AI 说：
> "帮我修复禅道 Bug #12345"

AI 将会自动启动 SOP 流程：
1. 询问禅道服务器地址（如果未配置）。
2. 分析 Bug 详情并请你补充必要的 Git 信息（仓库、分支等）。
3. 自动完成代码修复并给你发回 MR 链接。
