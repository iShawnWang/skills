# iShawnWang Skills

这是一个 AI 技能仓库，包含了一系列用于增强 AI 助手能力的自动化脚本、工作流和集成方案。

## 核心技能

### 1. GitLab 技能 (`gitlab-skills`)
提供了与 GitLab 实例深度交互的能力，支持：
- **用户信息查询**: 获取用户权限和 ID。
- **仓库管理**: 搜索和列出项目。
- **自动化合并**: 通过脚本自动创建并合并 Merge Request，支持仓库和分支的模糊匹配。

### 2. 乔乔车小程序发布技能 (`qqc-miniprogram-cli-skill`)
用于管理乔乔车小程序的自动化构建服务，支持：
- **触发构建**: 远程启动小程序打包任务（测试版、体验版等）。
- **状态监控**: 实时查询构建进度。
- **日志审计**: 获取详细的构建日志。
- **健康检查**: 监控 iMac 打包机的服务状态。

### 3. Alfred 工作流 (`alfred-workflows`)
包含一系列提升效率的 Alfred 工作流：
- **AI Search**: 增强的 AI 搜索工作流。

## 其他内容

- **personal_rules.md**: 定义了 AI 助手在当前环境下的全局行为准则和偏好。

## 使用须知

每个子目录下通常都包含 `SKILL.md`，提供了详细的 AI 调用指令和配置说明。在使用特定技能前，请先阅读相应的说明文件。
