# iShawnWang Skills

这是一个 AI 技能仓库，包含了一系列用于增强 AI 助手能力的自动化脚本、工作流和集成方案。

## 核心技能

### 1. GitLab 技能 (`gitlab-skill`)
提供了与 GitLab 实例深度交互的能力，支持：
- **用户信息查询**: 获取用户权限和 ID。
- **仓库管理**: 搜索和列出项目。
- **自动化合并**: 通过脚本自动创建并合并 Merge Request，支持仓库和分支的模糊匹配。

### 2. 乔乔车小程序发布技能 (`qqc-miniprogram-server`)
用于管理乔乔车小程序的自动化构建服务，支持：
- **触发构建**: 远程启动小程序打包任务（测试版、体验版等）。
- **状态监控**: 实时查询构建进度。
- **日志审计**: 获取详细的构建日志。
- **健康检查**: 监控打包机的服务状态。

### 3. Alfred 工作流 (`alfred-workflows`)
包含一系列提升效率的 Alfred 工作流：
- **AI Search**: 增强的 AI 搜索工作流。

### 4. [Spug 项目发布技能 (`spug-skill`)](https://github.com/iShawnWang/spug-skill)
用于管理 Spug 项目的自动化构建服务，支持：
- **触发构建**: 远程启动 Spug 项目的构建任务（测试版、体验版等）。
- **状态监控**: 实时查询构建进度。
- **日志审计**: 获取详细的构建日志。
- **健康检查**: 监控 Spug 项目的服务状态。

### 5. GitLab 周报生成技能 (`weekly-summary`)
自动收集并整理个人在 GitLab 上的开发活动，支持：
- **Commit 自动收集**: 获取指定时间段内的个人提交记录。
- **分支分组展示**: 报告按“项目 -> 分支 -> 提交”的三级结构展示，支持缩进。
- **变更统计**: 自动分析 Diff 并统计代码增删行数。
- **全中文输出**: 生成美观的中文 Markdown 报告。

### 6. 禅道 MCP 服务 (`zentao-mcp-server`)
内网禅道 HTTP 服务，用于登录 ZenTao/禅道实例，暴露 HTTP 接口查询、评论、指派、解决 Bug，支持：
- **登录检测**: 确认账号密码、Cookie、实例地址是否可用。
- **Bug 管理**: 获取指派给我的 Bug、Bug 详情、提交评论、指派、解决、关闭 Bug。
- **页面诊断**: 适配不同禅道版本或内网定制页面。
- **Bug 通知**: 对"新指派给我"的 Bug 做飞书通知。

### 7. 禅道 Bug 修复工作流 (`zentao-skill`)
禅道 Bug 修复自动化工作流，串联禅道、GitLab 并完成修复提交全流程，支持：
- **自动获取**: 从禅道获取 Bug 详情和上下文。
- **代码诊断**: 探索仓库结构、读取源码进行诊断。
- **自动修复**: 创建分支、编写修复代码、提交变更、创建 MR。

### 8. ShowDoc 文档获取 (`showdoc-skill`)
从 ShowDoc 文档系统获取页面内容并转换为 Markdown 格式，支持：
- **URL 解析**: 自动识别 ShowDoc 文档链接。
- **内容获取**: 调用 ShowDoc API 获取文档内容。
- **格式转换**: 转换为 Markdown 格式便于阅读。
